# parcel-delivery-management-system
A web-based Parcel Delivery Management System developed as a CSC403 software engineering project.

Parcel Delivery Management System

Project Overview
The Parcel Delivery Management System is a web-based application being developed as a CSC403 Software Engineering project. It is intended to help small and medium-sized courier businesses manage their daily delivery operations more efficiently.

Problem Being Addressed
Managing parcel deliveries through manual records, phone calls and WhatsApp messages can make it difficult to keep track of parcels, monitor rider assignments, update delivery statuses and maintain accurate records. This project aims to provide a centralised system for managing this information.

Project Objectives
- Record and manage incoming and outgoing parcels.
- Maintain sender and recipient information.
- Assign deliveries to riders.
- Track parcel delivery progress and outcomes.
- Record delivery charges and payment information.
- Make it easier to retrieve parcel information when customers make enquiries.
- Generate basic operational reports.

Main Features
The planned system will include:
- Dashboard
- Parcel management
- Rider management
- Delivery assignment and status updates
- Payment records
- Search and reporting

Technologies
- React
- JavaScript
- Firebase
- Git and GitHub

Development Methodology
The project will follow the **Incremental Development Model**. The system will be developed in smaller functional parts, with each increment adding features to the application.

Project Status
Currently in the planning and initial development stage.
